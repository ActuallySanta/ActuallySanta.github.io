Project Description


Don't Lose Your Head is a puzzle platformer made in a week with a team of 3 other programmers and 1 artist for the 2025 Scream Jam.

Play as a skeleton collecting as they navigate a haunted manor utilizing the fact that they can throw their head to activate conveniently placed levers and buttons to collect candy for their friends!

Contributions

Project Lead

  • Meetings

    Led periodic team meetings to determine tasks and rescope project

  • Team Check-ins

    Coordinated with team members to make sure that everyone was able to complete tasks, and if not, how to restructure the task to make it achievable

Programmer

  • Game State - Camera System

    Made a camera system that dynamically transitions between predetermined points based on the position of the player

  • Game State - Player Controller Refactor

    Debugged and Reworked the previously implemented Player Controller, using a Finite State Machine to control transitions to prevent jittery movement.

  • Game Art - Level Element Sprites
